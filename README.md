# Seamonkey

라즈베리 파이와 작은 화면으로 즐기는 씨몽키 키우기 게임입니다. 임베디드 SW입문 수업의 개인 프로젝트로 만들었습니다.

## 어떤 게임인가요

게임을 켜면 물이 담긴 어항이 보입니다. 처음에는 아무것도 없지만 조금 기다리면 아주 작은 씨몽키 다섯 마리가 태어납니다. 씨몽키는 날이 갈수록 조금씩 자랍니다. 다만 그냥 두면 배가 고파지고 심심해져서 결국 죽게 됩니다. 그래서 제때 먹이를 주고 같이 놀아 주면서 끝까지 키워 내는 것이 이 게임의 목표입니다.

## 어떻게 조작하나요

조이스틱을 위, 아래, 왼쪽, 오른쪽으로 밀면 그 방향으로 물살이 생깁니다. 물살이 생기면 씨몽키와 먹이가 그쪽으로 밀려갑니다. 5번 버튼을 누르면 먹이가 위에서 떨어지고 배부름이 올라갑니다. 6번 버튼을 누르면 씨몽키가 신나서 빠르게 헤엄치고 즐거움이 올라갑니다. 씨몽키가 죽었을 때 조이스틱 가운데를 누르면 첫째 날부터 다시 시작합니다.

화면 맨 위에는 오늘이 며칠째인지와 배부름, 즐거움이 막대로 보입니다. 두 막대 중 하나라도 다 떨어지면 씨몽키가 죽으니 막대를 잘 지켜봐야 합니다.

## 코드는 이렇게 나누어져 있습니다

이 게임은 역할마다 파일을 따로 만들었습니다. 파일 하나가 물건 하나를 맡는다고 생각하면 됩니다.

**main.py** 는 게임을 시작하는 파일입니다. 이 파일은 직접 일을 하기보다 다른 파일들에게 순서대로 일을 시키는 역할을 합니다. 먼저 조이스틱과 버튼이 눌렸는지 물어보고, 그다음 어항에게 한 장면만큼 시간을 흘려보내라고 하고, 그 결과를 그려서 화면에 보여 줍니다. 이 과정을 아주 빠르게 계속 되풀이하기 때문에 씨몽키가 움직이는 것처럼 보입니다. 게임을 끌 때는 화면을 끄고 지금까지의 상태를 저장합니다.

**Joystick.py** 는 화면과 조이스틱, 버튼을 맡습니다. 라즈베리 파이의 어느 핀에 화면이 연결되어 있고 어느 핀에 버튼이 연결되어 있는지를 이 파일이 알고 있습니다. 그래서 다른 파일들은 핀 번호를 몰라도 "지금 왼쪽을 누르고 있나요" 하고 물어보기만 하면 됩니다. 조이스틱을 민 방향을 물살의 방향으로 바꿔서 알려 주는 일도 여기서 합니다.

**Tank.py** 는 어항입니다. 어항은 씨몽키 다섯 마리와 떨어지는 먹이들을 데리고 있고, 오늘이 며칠째인지, 배부름과 즐거움이 얼마나 남았는지를 기억합니다. 시간이 지나면 배부름과 즐거움을 조금씩 줄이고, 다 떨어지면 씨몽키가 죽었다고 정합니다. 먹이 주기와 놀아 주기 버튼이 눌렸을 때 일어나는 일도 어항이 처리합니다. 또 배경 그림과 씨몽키 그림을 불러와서 한 장면을 그리고, 게임 상태를 파일에 저장했다가 다음에 켤 때 다시 불러옵니다.

**SeaMonkey.py** 는 씨몽키 한 마리입니다. 씨몽키는 자기가 어항 어디쯤에 있는지와 어느 쪽으로 가고 있는지를 스스로 알고 있습니다. 매 장면마다 가던 방향을 조금씩 바꾸면서 제멋대로 헤엄치고, 물살이 있으면 그쪽으로 밀려가며, 어항 밖으로는 나가지 않습니다. 그릴 때는 가는 방향을 바라보도록 그림을 좌우로 뒤집습니다. 이 설계도 하나로 다섯 마리를 만들기 때문에 다섯 마리가 저마다 다르게 움직입니다.

**Food.py** 는 먹이 알갱이 하나입니다. 먹이는 위에서 생겨나 천천히 아래로 가라앉고, 물살이 있으면 옆으로 조금 밀립니다. 바닥에 닿으면 사라집니다.

**background.png** 와 **seamonkey.png** 는 어항 배경과 씨몽키의 그림 파일입니다. 같은 이름으로 다른 그림을 넣으면 코드를 고치지 않아도 모습이 바뀝니다.

## 무엇이 필요한가요

- Raspberry Pi 4
- Adafruit 1.3인치 TFT Bonnet (240 x 240 화면, 조이스틱, 버튼 2개)
- Python 3

## 어떻게 실행하나요

라즈베리 파이에서 SPI를 켜고 아래 라이브러리를 설치합니다.

```
pip install adafruit-blinka adafruit-circuitpython-rgb-display pillow
```

그다음 이 폴더 안에서 아래 명령을 입력합니다.

```
python main.py
```

끌 때는 Ctrl+C를 누릅니다. 처음부터 다시 키우고 싶으면 `save.json` 파일을 지우고 다시 실행합니다.
